# 创建事项网页 Demo

独立的本地交互原型，不需要鸿蒙 SDK、模拟器、实机或 npm 依赖。不连接正式 preferences、系统卡片、GitHub 或任何远程服务。

## 启动

在仓库根目录运行（Node 18+）：

```sh
node demo/web/server.mjs
```

打开 http://127.0.0.1:4173 。如端口占用：`PORT=4174 node demo/web/server.mjs`。终端按 Ctrl+C 停止。也可以双击本目录的 `启动Demo.command`，再打开以上地址。

不要双击 HTML 运行：浏览器 ES 模块需要 HTTP 服务。修改 dist 内的源码会自动刷新页面；已填写的主页面草稿和原地配置自动保留。只有最终保存才写入已创建事项。

## 可以体验

- 名称直接创建；日期、计数、列表、记录、备注各有一个开关，在当前页面向下展开配置。
- 日期与天数只有一个位置，可在倒数日、正数日、截止时间之间切换；共用当前日期。
- 文字列表、修改文字、关联已创建且不含列表的事项；自动纳入最后未点击添加的文字。
- 本地草稿恢复、创建结果、已创建事项查看与编辑。
- 手机 390 × 844 / 平板 768 × 1024 应用视口；按实际单位预览，不通过放大字号填充桌面。
- 应用区域外顶部的演示工具：模拟下一次保存失败、加入关联示例、查看草稿 JSON、清空演示数据。

## 数据与边界

仅使用当前浏览器当前地址的 localStorage，键为 `todone-creation-lab-v1`。不同浏览器或端口的数据不共享。持久化写入成功后才展示成功，失败保留输入；重试按固定 ID 更新，避免重复。

这是探索性界面，使用 Demo 专用数据模型，不修改原生契约。新增日期方式、计数单位、草稿等字段尚未映射到正式 `MatterService`；不能把网页验证视为正式业务集成或 ArkUI 验收。日期和时间使用 Demo 选择窗，字体由本机系统渲染；这两项不能视为 HarmonyOS 原生控件的最终外观。视口不包含系统状态栏、导航栏与键盘，不模拟鸿蒙设备性能。记录/计数的日常使用动作不属于本创建 Demo。

## 文件

- `dist/index.html`：页面外壳。
- `dist/style.css`：按现有 ArkUI 字号、尺寸和结构编写的页面样式。
- `theme-sync.mjs`：直接读取原生 `Theme.ets`，动态生成 `/native-theme.css`；不复制配色。
- `theme.test.mjs`：检查网页引用的设计值均来自原生主题。
- `dist/app.mjs`：流程状态、面板、草稿与独立浏览器存储。
- `dist/model.mjs`：无 UI 依赖的校验、日期显示与幂等更新。
- `server.mjs`：仅绑定 127.0.0.1 的静态服务器和修改刷新。

## 视觉对齐约定

用户要求 Demo 尽量所见即所得，最终接回原生时沿用这里确认的页面结构与尺寸，不另做网页品牌风格。现有 ArkUI 源码是当前视觉基准；重构后的布局仍是待用户确认的方案。

| 项目 | 来源与映射 |
| --- | --- |
| 全部应用颜色、圆角、间距 | `app/entry/src/main/ets/common/Theme.ets`，服务端直接读取；修改原生主题后自动刷新 |
| 页面边距、卡片内边距、区块间距 | `Space.large` = 16 vp，对应 16 CSS px |
| 卡片 / 控件圆角 | `Radius.large` = 18；`Radius.normal` = 12 |
| 页面标题 / 区块标题 | 原创建页 24 / 18；标题加粗 |
| 名称输入 / 通用输入 | 原创建页高度 46 / 44，字号 17 / 15 |
| 创建按钮 | 原创建页全宽、高 46、字号 16，位于内容下方 |
| 次级按钮 / 说明 | 原创建页字号 14 / 13 |
| 配置区域 | 每种信息在原行下方展开；与主页面共用主题及控件规格 |

移除旧 Demo 的暖绿配色、侧栏、大标题、插画装饰、额外图标配色和大卡片阴影。工具条只属于浏览器开发环境，不能迁入 App。应用内滚动、面板宽度、背景遮罩均受预览视口约束。

这些约定使颜色、圆角、间距可直接复用，布局可按 vp 迁移；HTML/CSS 不是 ArkUI 源码，原生 Navigation、字体字形、DatePicker、输入法及系统动画仍需后续原生预览/设备核对，尚未声称像素级一致。请保持浏览器缩放 100%；CSS px 与设备物理像素并非同一概念。
