## 0. 先看权限

| 层级 | 管什么 | Agent 权限 | 记录 |
|---|---|---|---|
| **L0 身份** | 纸/墨/朱红角色、簇色角色、字体角色、圆角档、线语义、无阴影/渐变、夜纸、对比度/热区下限 | 不可改 | 改需更新本文与 [决策记录](../DECISIONS.md) |
| **L1 默认** | 字号/间距档、卡片结构、按钮类型、状态样式、簇与拖拽反馈、动效默认、服务卡片默认 | 先用默认；偏离写一句理由 | PR 描述一句话 |
| **L2 组合** | 卡片是否带操作、操作数量/位置、模块顺序与呈现、页面分组与密度、空态/加载/错误文案、平板布局 | 按功能自主决定 | 不必事先批准 |
| **L3 新范式** | 新颜色/字体、改线语义、去掉夜纸、加阴影/渐变、全新页面结构 | 先提案/确认 | 更新 [决策记录](../DECISIONS.md) |

判断标准：

> **不改变品牌识别、不改变交互语义、不降低可访问性，Agent 可以直接做；三者任一被改变，就必须记录或确认。**

冲突时的优先级：

> **可用性 > 身份 > 功能 > 布局/装饰。**

功能与文档冲突时，先保证可用性和功能，再套用最接近的默认模式；只有触碰身份项才停下来确认。**不要为了符合文档删功能，也不要为了填满文档硬塞不存在的控件。**

## 1. 身份（L0）

### 1.1 颜色 Token

| 角色 | 亮纸 | 夜纸 | 用途 |
|---|---|---|---|
| `paper.bg` | `#FAF6EE` | `#191714` | 页面底 |
| `paper.card` | `#FEFCF7` | `#201D19` | 卡片、输入、浮层、服务卡片底 |
| `paper.ink` | `#23211C` | `#EFE9DC` | 标题、正文、图标 |
| `paper.inkSoft` | `#57544B` | `#C0B8A9` | 次要文字、浅底上的说明文字 |
| `paper.inkMuted` | `#68635A` | `#A79F91` | 时间、提示、元信息、占位符；信息文字不低于此 |
| `paper.hairline` | ink 13% | ink 16% | 卡片边、分隔线（对象边界，非控件边界） |
| `paper.line` | = inkMuted | = inkMuted | 勾选框等需要可识别边界的控件，1vp |
| `paper.track` | ink 6% | ink 10% | 进度轨道 |
| `paper.wash` | ink 7% | ink 10% | 搜索底、选中筛选底、次按钮底、按压态 |
| `accent.red` | `#C73E1D` | `#E8755A` | 朱红：主操作、危险、紧急、NOW、错误、光标 |
| `accent.on` | `#FEFCF7` | `#191714` | 朱红实心底上的文字/图标 |

- 百分比色 = ink 按该不透明度叠在所在底色上；hairline 容差：亮 10–16%，夜 12–18%。
- 夜纸不用纯黑/纯白；同一角色换值，不换语义。**夜纸朱红偏亮，实心按钮上必须用深色字（`accent.on`）**，白字只有 2.95:1。
- 不要把 `#98938A` 或更浅的灰用作信息文字（纸底 2.83:1）。

**已核对的对比度**（WCAG 2.x 公式，演示页可实时复算）：

| 组合 | 亮纸 | 夜纸 | 要求 |
|---|---|---|---|
| ink / inkSoft / inkMuted 在 `paper.bg` | 14.9 / 7.0 / 5.5 | 14.8 / 9.1 / 6.8 | ≥4.5 |
| inkMuted 在 `paper.wash`（搜索占位符） | 4.8 | 5.3 | ≥4.5 |
| 朱红文字在 `paper.card` | 4.95 | 5.7 | ≥4.5 |
| `accent.on` 在朱红实心 | 4.95 | 6.1 | ≥4.5 |
| `paper.line` 在 `paper.card` | 5.8 | 6.4 | 控件边界 ≥3 |
| 簇色在 `paper.card`（最低为山吹黄） | ≥3.3 | ≥7.2 | 标记 ≥3 |

### 1.2 簇色（只做标记）

| 角色键 | 名称 | 亮纸 | 夜纸 |
|---|---|---|---|
| `cluster.pine` | 松花绿 | `#2E6E62` | `#8BBFAF` |
| `cluster.wisteria` | 藤紫 | `#6A5C8C` | `#B3A2D4` |
| `cluster.kerria` | 山吹黄 | `#B9822C` | `#DDB26A` |
| `cluster.indigo` | 黛蓝 | `#3B5F86` | `#93AFCF` |
| `cluster.ink` | 墨 | `#23211C` | `#EFE9DC` |

- **朱红不是簇色。** 朱红只表达强调语义，不表达「属于哪一组」，避免和紧急/危险混淆。
- 簇色只出现在左杠、色点、进度和 8–10% 浅底上；**不给任何文字上色**（山吹黄在卡片上只有 3.3:1）。
- 浅底上的文字用 ink / inkSoft，不用 inkMuted。
- 新建簇按上表顺序循环取色。落地时簇以角色键存储，才能在夜纸换值；旧数据中的色值需要迁移映射，属于数据迁移，按工作约定先给方案再实施。新增簇色属于 L3。

### 1.3 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 展示 | ZCOOL QingKe HuangYou（站酷庆科黄油体），只打包所需字形 | **只用于固定页面标题**（事项、时间线、新建事项等）：30fp，单一字重 |
| 正文 | 系统默认中文无衬线（HarmonyOS Sans SC） | 标题、正文、按钮、元信息、用户输入的一切内容 |
| 数据 | JetBrains Mono，仅数字/拉丁/标点子集 | 数字、日期、计数；不承载中文 |

- 展示体**不用于用户内容**（事项名、输入框）：子集字体覆盖不了任意用户文字，会出现混排字形。详情页事项名用正文 24fp/600。
- 回退链固定：展示体 → 正文字体 600；数据字体 → 正文字体（开启等宽数字）。不改变字号与层级，不静默换成第二套展示字体。
- 字体需确认商用许可与打包体积；未打包时接受回退，不因此改设计。服务卡片默认不使用展示体（见 §2.9）。

### 1.4 圆角、线与效果

- 圆角：卡片、按钮、输入、搜索 4vp；chip、小标记、勾选框 3vp。禁止大圆角、胶囊按钮。服务卡片外框圆角由系统决定。
- 线：事项卡用 1vp hairline；**操作控件（按钮、筛选、搜索、视图切换）不加描边**；勾选框用 1vp `paper.line`；输入框默认 wash 底不描边。不做 100% 墨线卡片，不做双线规。
- 效果：不用阴影、模糊、玻璃、渐变、纹理、emoji。唯一例外是拖拽态的硬边错位投影（§2.6）。

### 1.5 九条硬规则

1. **纸，不是屏幕**：只用纸底、卡纸、墨色系；不用纯白/纯黑。
2. **朱红只表达语义**：可用角色为主操作、危险、紧急、NOW、错误、输入光标；不做装饰、分类、簇色。**同屏同时出现的朱红角色不超过 3 种**（光标不计）；同一角色重复出现（如多张卡「今天截止」）不额外计数，但重复项只用文字，不加色块或色杠。
3. **朱红文字的边界**：只允许危险操作文字、紧急 meta、错误提示，字重 600、≥12fp，只放在纸/卡底上，不放在朱红浅底上。
4. **簇色只做标记**：左杠 3vp、色点 8vp、进度 3vp、浅底 8%（夜 10%）；不给文字上色。
5. **线语义**：卡片边表达「这是事项对象」，不表达「选中/当前」；选中用浅底、字重或标记，不加框。
6. **微圆角**：4vp / 3vp 两档。
7. **字体角色**：展示体只给固定页面标题；正文 ≥13fp；元信息 ≥12fp；数字/日期用 mono。**不用 11fp 及以下承载信息。**
8. **夜纸必须支持**：同一结构、同一线语义；换 token，不换风格；默认跟随系统深浅色。
9. **可访问性**：信息文字 ≥4.5:1；控件边界与标记 ≥3:1；可点热区必须 ≥40×40vp，推荐 48×48vp（视觉更小时扩大热区）；跟随系统字体缩放，大字体下换行而不截断关键信息。

## 2. 默认模式（L1）

这一节是「先用这个」的默认，不是逐屏规格。参考图是 B 的首页强度；其他页面按同一套 token 推导。

### 2.1 字号与行高

| 档位 | 字体 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|---|
| `type.display` | 展示 | 30/38（平板 32/40） | 单一 | 固定页面标题 |
| `type.heading` | 正文 | 24/32 | 600 | 详情页事项名、新建页名称输入 |
| `type.title` | 正文 | 16/22 | 600 | 事项卡标题 |
| `type.body` | 正文 | 14/21 | 400 | 正文、按钮 |
| `type.bodySmall` | 正文 | 13/20 | 400 | 备注、副标题、提示条 |
| `type.meta` | 正文 + mono | 12/17 | 400 | 元信息、底部提示 |
| `type.figure` | mono | 24/30 | 600 | 服务卡片与详情页的主数值 |

只用 400 / 600 两档字重；字距默认 0。

### 2.2 间距与尺寸

间距档：`4 · 8 · 12 · 16 · 20 · 24 · 32`，不取档外值。

| 位置 | 默认值 | 容差 |
|---|---|---|
| 页边距 | 手机 20，平板 24 | 20–24 |
| 标题区 → 搜索 | 20 | 16–24 |
| 搜索 → 筛选 | 12 | 8–12 |
| 筛选 → 卡片流 | 16 | 12–20 |
| 卡片内距 | 16 | 14–16 |
| 卡间距（不同簇或无簇） | 12 | 12–14 |
| 同簇卡间距 | 4 | 4–6 |
| 标题 → 备注 / 备注 → meta | 4 / 8 | — |

| 控件 | 视觉高度 | 热区 |
|---|---|---|
| 主按钮、搜索、次按钮 | 40 | ≥48 推荐（扩大响应区） |
| 文字按钮、卡内操作行 | 44 | ≥44 |
| 筛选项 | 32 | ≥40 |
| 勾选框 | 20×20 | 48 |
| 图标按钮 | 图标 20，容器 40 | ≥40 |

### 2.3 首页骨架

状态栏 → 标题区 → 搜索 → 筛选 → 事项卡流 → 底部提示 → Home 指示条。

- 标题区：页面标题（`type.display`）+ 副标题（`type.bodySmall`，inkSoft，数字 mono）；右侧文字按钮 + 「+ 新建」主按钮。
- 没有品牌头 `TODONE`、没有双线规、没有英文模块标注、没有标题红点。
- 搜索：wash 底、无描边、20vp 线性搜索图标、占位符 inkMuted；获得焦点时底部 2vp ink 下划线，光标朱红。
- 筛选：文字式；选中为 wash 底 + ink 600，未选中为 inkSoft 400；不加框。
- 底部提示：`type.meta`，inkMuted。

### 2.4 按钮类型

所有按钮无描边、4vp 圆角。

| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | 朱红实心 + `accent.on` 600 | 每屏最多 1 个：新建、保存 |
| 次按钮 | wash 底 + ink 600 | 需要块面但不是主操作：服务卡片「记录」、对话框取消 |
| 文字按钮 | 无底，ink 600（主要）/ inkSoft 400（次要） | 打开、时间线、归档 |
| 危险文字按钮 | 无底，朱红 600 | 删除、确认删除 |

按压态：叠加 wash（实心按钮叠加 ink 12%）；禁用：整体 40% 不透明度，不改颜色角色。

### 2.5 事项卡与簇

- 卡纸 + 1vp hairline + 4vp 圆角；内距 16。
- 结构：标题（`type.title`）→ 备注（`type.bodySmall`，inkSoft，最多 2 行）→ meta（`type.meta`，inkMuted，数字/日期 mono，项之间用「 · 」）→ 进度 3vp（可选，轨道 `paper.track`）。
- **默认不带操作行**；点卡片进详情，长按拖拽。默认不用彩色 chip。
- **簇标记**：属于簇的卡片在左边缘内侧画 3vp 簇色竖杠（方头，上下贴卡片内边，随圆角裁切）；进度条同色。无簇的卡片不画标记，也不画灰色占位。
- **簇的聚拢**：同簇相邻卡片间距 4，不同簇之间 12；不画外框、不加簇名、不折叠，以免变成文件夹。
- 色点（8vp）只用于空间不足处：服务卡片行、列表里的事项引用、时间线。
- 紧急 meta（今天截止、已过期）：只把该段文字改为朱红 600，不改卡片边和底色。

### 2.6 卡内操作（可选模式）

如果功能确实需要在卡内暴露操作：

- 卡片底部 hairline 分隔后一行文字按钮，高 44，最多 3 个：打开（ink 600）/ 归档（inkSoft）/ 删除（朱红 600）。
- 不用 5 个并排按钮；上移/下移交给长按拖拽或详情页。
- 展开的卡不加强边框；操作行本身就是展开的表达。
- **出现与否是 L2，样式是 L1。**

### 2.7 拖拽：排序与成簇

| 状态 | 表现 |
|---|---|
| 抬起（长按触发） | 原位留 1vp 虚线空位框（ink 40%，同高同圆角）；被拖卡片跟手，背后叠一块硬边错位投影：ink 12%，向右下偏移 4vp，无模糊 |
| 排序中 | 空位框随落点移动；其他卡片 160ms 让位 |
| 成簇目标（悬停在目标卡片中部） | 目标卡底色变为将加入的簇色 8%（夜 10%），左缘预显簇色杠，meta 行替换为「松手加入关联」（inkSoft）；**不加边框** |
| 松手成簇 | 两张卡获得同一簇色杠并靠拢；底部提示条「已建立关联 · 撤销」 |
| 移出簇 | 从详情页或长按菜单的「移出关联」文字按钮完成；首页卡片不常驻该按钮 |

如果目标 SDK 无法自定义拖拽预览，则用系统默认预览并保留空位框与成簇目标态，作为 L1 偏离在 PR 中说明（待最小验证）。

### 2.8 状态与反馈

| 状态 | 默认 |
|---|---|
| 焦点（键盘/无障碍） | 2vp ink 内描边或下划线，只在焦点时出现 |
| 空态 | `type.bodySmall` inkSoft 一句话 + 可选文字按钮；不加插图/emoji |
| 加载 | 「正在读取…」（inkMuted），或静态 wash 占位块；不用闪光骨架（属于渐变） |
| 错误 | 字段下方朱红 600 `type.meta` 一句话；输入下划线改为 2vp 朱红 |
| 提示条 | 底部、卡纸底 + hairline + 4vp 圆角，`type.bodySmall` ink，可带「撤销」文字按钮；3 秒消失；无阴影 |
| 二次确认 | 危险按钮原位变为「确认删除」并在提示条说明；不弹全屏遮罩 |

### 2.9 图标

- 线性图标，描边 1.5vp，图标 20vp，置于 ≥40vp 热区；颜色 ink / inkSoft。
- 优先系统 Symbol 的单色线性样式；不用多色或填充图标；朱红图标只在危险操作且与文字同现时使用。

### 2.10 动效

- 默认 160ms，`cubic-bezier(0.2, 0, 0, 1)`；展开/收起、让位、浅底切换都用这一档。
- 不用弹簧、回弹、缩放超过 1.02、模糊过渡。系统关闭动画时直接切换。

### 2.11 夜纸

- 默认跟随系统深浅色模式（亮/夜两套颜色资源，同名角色）；App 内是否提供手动切换属于 L2。
- 同一结构、同一线语义；hairline 16%、wash 10%、簇浅底 10%；朱红实心按钮用深色字。

### 2.12 服务卡片

- 使用同一套 token 与夜纸映射；卡片底 `paper.card`，外框圆角与尺寸由系统决定。
- 卡片本身就是对象边界：卡内不再套 hairline 卡片；行与行之间用 hairline 分隔或 8vp 间距。
- 字体：标题 `type.body` 600，主数值 `type.figure`，meta `type.meta`；不使用展示体；数据字体能否在卡片中加载需验证，否则用系统字体等宽数字。
- 簇用 8vp 色点；每张卡片最多 1 种朱红角色；快捷操作用次按钮（wash 底），高 40。
- 2×2 单事项：事项名 → 主数值 → meta → 可选快捷操作。2×4 汇总：整卡点击进入 App 时最多 4 行（行高 28），每行色点 + 事项名 + 右侧 mono 数值；若每行单独可点，行高须 ≥40，相应减为 3 行。

### 2.13 文案与数字

- 中文为主；数字、日期、计数用 mono；默认截止格式：`截止 11.28 · 还剩 8 天`，紧凑处可用 `D-8`。
- 不显示英文模块名；提示语短，不用感叹号、emoji。
- 文案属于 L2；格式角色（mono/字号）属于 L1。

### 2.14 其他页面的推导默认

B 目前只出了首页；以下是按身份推导的方向，出图后补示例。

## 3. 组合自由（L2）

Agent 可以自主决定：

- 卡片是否带操作、操作数量与位置（卡内/详情/长按）。
- 模块顺序、是否显示某个模块、模块信息用 meta 文字还是标记（不加新颜色）。
- 页面 section 顺序、分组、卡片数量、密度。
- 空态、加载、错误的文案与位置；是否提供夜纸手动切换。
- 图标选择、文案长度、响应式和平板布局。

两条原则：**有默认用默认；没默认按功能做。功能决定「有没有」，文档决定「长什么样」。**

例子：产品预期事项卡不带控件 → 不渲染操作行；新模块没有对应 chip → 用 meta 文字 + mono 数字；平板两栏 → 同一套 token 重排；空态没有插图 → 文字 + 纸面留白。

## 4. 偏离与新范式（L3）

以下情况先提案/确认，并更新 [决策记录](../DECISIONS.md)：

- 新增颜色、字体、第二强调色，或把朱红用作簇色/装饰。
- 改线语义：给控件加框、给卡片加 100% 墨框、恢复双线规。
- 去掉夜纸，或改夜纸的角色映射。
- 加阴影、模糊、玻璃、渐变、纹理。
- 需要一套现有模式拼不出的新页面结构。

流程：L1 偏离在 PR 描述写一句「设计偏离：……（原因）」；L3 先说明影响与替代方案，确认后进 DECISIONS，成为常态再回写本文。不新建独立的设计日志文件。

文档没写的地方不是禁止：先找最接近的默认；找不到再按功能组合；组合不出来才是 L3。

## 5. 允许 / 不允许 / 需确认

**允许**：事项卡不带操作行；新模块用 meta 文字；平板两栏、卡片更密（仍在容差内）；空态只用文字；某页不需要搜索/筛选就不渲染；目标 SDK 不支持时用系统拖拽预览。

**不允许**：
- 给搜索、筛选、视图切换、按钮加 1vp 描边（勾选框必要边界不算）。
- 给事项卡加 100% 墨线框、双线规，或用边框表示选中/拖拽目标。
- 朱红做装饰/分类/簇色，或同屏超过 3 种朱红角色。
- 用 11fp 及以下文字承载信息，或给任何文字上簇色。
- 夜纸朱红按钮用白字；用 `#98938A` 及更浅的灰做信息文字。
- 加阴影、渐变、纹理、玻璃、闪光骨架、第二套标题字体；展示体用于用户内容。
- 去掉夜纸。

**需确认**：新增簇色/字体/强调色；hairline 超出容差或改线语义；改圆角档或主色；引入新的页面骨架。

## 6. 验收

不逐像素对照参考图，检查这些可测项：

- [ ] 颜色全部来自 token 角色；夜纸同样成立，无纯黑/纯白；夜纸主按钮为深色字。
- [ ] 信息文字 ≥4.5:1（含占位符）；控件边界与簇标记 ≥3:1；没有文字使用簇色。
- [ ] 正文 ≥13fp、元信息 ≥12fp；只有 400/600 两档字重；展示体只出现在固定页面标题。
- [ ] 系统最大字体下标题、meta 换行而不重叠，关键信息不被截断。
- [ ] 热区 ≥40vp（主要操作 48vp）；32vp 筛选项与 20vp 勾选框已扩大热区。
- [ ] 事项卡为 hairline；按钮/筛选/搜索 0 描边；勾选框 1vp `paper.line`；没有用边框表达选中或拖拽目标。
- [ ] 同屏朱红角色 ≤3 种，且都在允许的角色表内。
- [ ] 簇卡片有 3vp 左杠、同簇间距 4；无簇卡片无标记；拖拽有空位框和成簇目标态。
- [ ] 没有阴影/模糊/玻璃/渐变/纹理/emoji；拖拽硬边投影是唯一例外。
- [ ] 手机、平板与服务卡片使用同一套 token。

真机上的字号、系统栏、键盘、字体回退和拖拽预览仍需单独验证。
