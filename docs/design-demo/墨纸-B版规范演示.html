增强预览改了什么

  • 纸底调深一档（亮 #F3EEE3 / 夜 #141210），让卡片从纸面上浮出来。
  • 首页卡片右上角给出大号主值（19px 600，允许簇色），meta 数字用墨色 600 落点。
  • 详情页顶部加主视觉区：簇浅底 + 展示体标题 + 44px 主属性大数字。
  • 详情页模块拆成卡片，区块标题改 13px 600 墨色，不再全平铺。
  • 联网时自动加载站酷庆科黄油体与 JetBrains Mono，离线无阻塞回退。

颜色与对比度

数值按当前纸面实时计算（WCAG 2.x）。文字要求 ≥4.5，控件边界与标记要求 ≥3；hairline 是对象边界，不承担识别控件的职责。

字号与行高

只用 400 / 600 两档字重。展示体只用于固定页面标题，不用于事项名等用户内容。
