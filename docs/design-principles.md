# 设计原则

## 产品边界

- 只围绕「事项」组织信息。
- 不要求用户选择事项类型、标签、分类或项目层级。
- 创建事项时先选择需要的信息入口；不先创建空事项再让用户到处补配置。
- 短期备忘、临时日期和长期事项都可以使用同一套创建流程。
- 首页是事项管理页，不是 Dashboard。
- 截止日期是可选信息；选择后自动派生倒计时，不要求用户重复配置。
- 日期优先使用快捷选项和原生日期选择器，不以手填格式作为主要入口。

## V1 默认风格

- 现代明亮风格。
- 高辨识度颜色用于表达弱关联簇。
- 操作入口直接可见，不藏进右上角菜单。
- 卡片和页面都使用中文 UI 文案。

## 首页

首页承担：

- 查看所有未归档事项
- 创建事项并选择记录信息
- 搜索事项
- 排序事项
- 建立或解除弱关联簇
- 进入事项详情

列表详情可以添加文字项，也可以创建并关联独立事项；关联事项仍然在首页保持独立展示。

首页不承担：

- 今日任务
- 本周计划
- 全局时间轴
- 活跃目标统计
