# 模块系统

需求以 [产品规格](../PROJECT_SPEC.md) 为准，下表描述当前 V1 实现范围，不表示实机验收通过。实现参考 [详情页](../app/entry/src/main/ets/pages/MatterDetail.ets) 与 [存储层](../app/entry/src/main/ets/store/MatterStore.ets)，修改行为时同步表格。

模块用于描述事项需要哪些记录能力，而不是把事项划分为类型。

## V1 模块

| 用户可见名称 | 用途 | V1 行为 |
| --- | --- | --- |
| 事件记录 | 记录某件事发生的时刻 | 点击「记录一次」生成时间记录 |
| 计数 | 累加数值或每日一次 | 支持 `+1`、`+10`、自定义数值、今日一次 |
| 进度 | 展示完成度 | 支持手动百分比 |
| 截止日期 | 保存关键日期 | 保存日期和可选地点 |
| 倒计时 | 基于截止日期展示剩余天数 | 不重复存储日期 |
| 备注 | 自由文本 | 保存短文本说明 |
| 列表 | 简单条目清单 | 条目只有标题和完成状态 |

## 明确不做

- 列表项不能再拥有模块。
- 不做公式引擎。
- 不做任务、项目、目标、习惯等对象类型。
- 不做传统标签和分类。

## 配置策略

每个模块实例保存 `configJson`。V1 用简单 JSON 支持快速迭代；当某类模块稳定后，再拆出专用存储结构。
