# 信息模块

需求以 [产品规格](../PROJECT_SPEC.md) 为准，下表描述当前实现范围，不表示实机验收通过。实现参考 [创建编辑页](../app/entry/src/main/ets/pages/CreateMatter.ets)、[详情页](../app/entry/src/main/ets/pages/MatterDetail.ets) 与 [领域状态](../app/entry/src/main/ets/domain/MatterState.ets)，修改行为时同步表格。

信息模块描述事项需要哪些能力，不把事项强行拆分成任务、习惯或独立日程实体。无论从主页还是时间线新建，均进入统一的创建页选择信息选项卡，已创建事项可在主页、时间线或详情页进入编辑。

## V1 模块

| 用户可见名称 | 用途 | 行为说明 |
| --- | --- | --- |
| 时间 | 安排时间段、截止时刻或关键日期 | 三段切换「全天 / 时间段 / 截止时刻」，底部胶囊按需开启「倒数/正数天数、提醒、重复」；时间段事项自动进入时间线并在主页按日期筛选浮现 |
| 标签 | 颜色与纯文字分类标记 | 选择已有颜色分类或新建自定义颜色标签（纯文字，不含 emoji） |
| 计数 | 合并原计次与计数 | 内分「计次（每次 +1）/ 计量（自定义单位与 1~2 个快捷步长）/ 每日打卡（统计连续与累计天数）」，统一支持当次短备注与流水撤回 |
| 备注 | 补充文字、链接与图文资料 | 支持自由文本、HTTP(S) 链接识别点击，以及从系统相册/文件选择器添加图片、文件与音频附件 |
| 列表 | 文字项和事项引用 | 支持完成状态、原地修改文字项、打开独立关联事项 |

倒数/正数天数直接由「时间」模块派生计算，不再额外写入冗余的 `Countdown` 模块实例。旧数据中的 `EventRecord`（记录）、顶层 `description` 与日期 `location` 在读取和编辑时无损合并到「计数（计次模式）」与「备注」模块中。

## 列表与关联事项

列表既可以放普通文字项，也可以放独立事项引用。例如“本学期要做的事”可以关联“六级考试”和“雅思考试”，每个考试仍然拥有自己的时间段、倒数天数和备注。

V1 只允许一层关联：关联事项不能再拥有自己的事项列表。关联不是所有权关系，删除列表项只解除关联，删除主事项也不会删除被关联事项；被关联事项可独立出现在首页和卡片中。

## 明确不做

- 不把进度作为用户可选模块；旧数据和接口仅保留兼容读取。
- 不在时间模块提供独立的地点输入框（地点信息统一写入备注）。
- 标签不使用 emoji 表情，仅用颜色与文字标记。
- 不做多级项目树、父子事项或自动级联删除。
- 不做公式引擎。

## 配置策略

每个模块实例保存 `configJson`，同一事项中每种模块最多启用一份；关闭模块时保留草稿或 `disabledModules` 配置，重新开启可恢复。
