# 新建事项 · 信息筛选稿

「时间线添加面板」一节已于 2026 年 11 月 13 日冻结，配套[独立可打开的 v1 原型](assets/timeline-editor-v1.html)。其他章节保留调研和候选项，单卡排版与额外模块仍可单独讨论。双日浏览和卡片排程见[时间线手册](timeline.md)。

## 参考操作

手机录屏长约 54 秒。以下时间为近似值。

| 时间 | 录屏中可见的操作 |
| --- | --- |
| 00:00–00:13 | 从清单点加号，创建面板上滑，键盘打开。输入「组会」，打开有颜色的清单菜单，可选已有清单、新建或不归入清单。 |
| 00:14–00:28 | 进入描述编辑，输入「汇报ppt」后返回，标题和已选清单仍在。日期提供今天、明天、选择日期、待办箱，演示中切换了今天和明天。 |
| 00:29–00:39 | 在子任务栏输入「报告」，选择较高难度，打开提醒的时、分选择器。主面板保留在后方。 |
| 00:40–00:53 | 查看重复规则、照片／拍照，尝试在标题插入 #，打开 AI 灵感后返回。最后回到清单，录屏没有展示可辨认的新增结果。 |

《Todo清单核心功能与交互调研报告》记录的是 macOS 3.14.0。第 7 页实测了待办箱只输入标题即可创建，随后补描述、子任务，把日期设为今天后能在今日列表中找到同一事项。第 11–14 页列出提醒、重复、图片、工作量等详情入口，并区分看见入口与实际执行。手机录屏中的「添加」和桌面详情编辑各自有不同的提交方式。

## ToDone 当前可设置的信息

| 信息 | 创建时 | 创建后及卡片上的表现 |
| --- | --- | --- |
| 事项名称 | 唯一必填，去除首尾空白后须有内容 | 首页、详情、桌面卡片共用标题。 |
| 说明 | 可选短文本 | 首页事项行显示一行，详情可改。 |
| 截止日期、地点 | 启用截止日期后选日，可选今天、明天、本周末、下周或指定日期，地点可空 | 详情可改。界面只选年月日，倒计时按截止日期派生。地点当前附属于截止日期。 |
| 备注 | 启用备注后可填自由文本 | 详情可以持续修改，数据与「说明」分开。 |
| 文字列表 | 可添加多条初始文字项，也可移除 | 逐项勾选，生成已完成数／总数。 |
| 关联独立事项 | 从某个既有事项的列表发起创建，可把新事项加入该列表 | 可在详情新建或关联已有事项，限一层。解除引用后，目标事项可继续独立使用。 |
| 发生记录 | 可启用记录，无需预填时间 | 点「记录一次」才生成实际发生时间，可以看记录和今日次数。 |
| 计数 | 可启用计数 | 使用时可 +1、+10、输入自定义数值或「今日一次」，产生今日值、累计值。 |
| 首页排序、弱关联、归档 | 在首页操作 | 排序、簇归属／簇色、归档／恢复属于事项管理。整项归档和文字列表项完成有各自的状态。 |
| 桌面服务卡片绑定 | 在「卡片设置」单独选择 | 单事项卡选 1 项，汇总卡最多 3 项。标题、模块摘要、颜色、主要数值和快捷动作由所选事项产生。 |

当前 App 首页事项行还会列出已启用的信息模块，簇内事项带「弱关联」提示。桌面单事项卡的主要摘要按记录、计数、列表、倒计时、模块摘要的顺序取用，快捷动作由模块决定为「记录」「+1」或「打开」。事项 ID、创建／更新时间、卡片绑定标识由系统管理。模型保留旧进度和截止时刻标志，当前创建界面均无对应编辑控件。

首屏卡堆和 Timeline 效果图另含类别色、开始／结束时刻、持续时长、全天区和勾选圆圈。其中时间段尚未接入创建模型。独立时间块的颜色来自所选标签，整项完成语义待定，当前已有清单勾选作用于文字列表项。代码入口见[创建页](../../app/entry/src/main/ets/pages/CreateMatter.ets)、[事项详情](../../app/entry/src/main/ets/pages/MatterDetail.ets)、[模型](../../app/entry/src/main/ets/model/Types.ets)、[首页](../../app/entry/src/main/ets/pages/Index.ets)及[桌面卡片设置](../../app/entry/src/main/ets/pages/WidgetPreview.ets)。

## 排程候选信息

| 用户知道什么 | 候选输入 | 建议的呈现与结果 |
| --- | --- | --- |
| 只知道要做什么 | 标题 | 可直接保存成卡片，之后给同一事项排时间。 |
| 知道哪天做 | 计划日期 | 在选定日可找到，具体时段留空。日期选择可沿用正在浏览的日期作快捷选项。 |
| 只知道大约要多久 | 预计时长 | 可先记 30 分钟，之后找至少 30 分钟的空档。尚未排入时段时不计入已占时间。 |
| 知道几点做 | 计划日期、开始时刻，以及结束时刻或时长 | 结束与时长互算。例如 11:00 加 1 小时得到 12:00，用这段时间绘制便签。 |
| 确实覆盖整天 | 全天标记和日期 | 显示在全天区。只选日期的普通待办仍可在当天另找空档。全天如何计入忙闲待讨论。 |
| 知道最晚何时交 | 截止日期，可与计划并存 | 周四写报告、周五交报告，可分别记录。当前已有日粒度截止日期，精确截止时刻另议。 |
| 担心忘记 | 提醒时刻，或相对开始／截止提前多久 | 用户启用才询问。提醒时刻独立于实际占用时段。 |

现有的地点可讨论是否独立出来，让有地点的组会无需额外设截止日期。说明与备注可先只露一个「补充说明」入口，已有两份文本的事项仍须能分别访问原内容。

## 时间线添加面板

2026 年 11 月 15 日更新了原生备注的附件入口与网址识别。11 月 13 日的 v1 原型保留当时的交互。

从 Timeline 的「＋」创建独立日程时，面板从底部上滑，首层显示标题、开始和结束。日期沿用时间线选中日，填写标题并确认时段即可保存。

名称、备注和标签名输入框获得焦点时显示光标，隐藏提示字，避免整块白底或粗外框；留空移开后恢复提示。冻结原型在移动开始时保留当前时长，单独移动结束则改变时长。

点开始或结束的**时刻**，小时、分钟在该行正下方居中展开为两列紧凑滚轮。当前时刻落在浅灰色圆角选中带内，相邻数字略小，外侧数字再淡一级。保持逐分钟选择，重新打开时显示草稿中的精确时刻。切换到另一行时，滚轮跟随切换。点对应的**日期**或下拉日期栏，顶部当周那一行原位展开，月历其余日期逐渐露出，把同页的表单向下推。选中态只包住日期数字，呈圆形。在月历区域继续上滑或下滑可浏览相邻月份，始终停在选日层。点选某天，日期栏收回到该日所在的一周，编辑面板重新占据页面大部分空间。跨午夜时可单独选择结束日期。

| 入口 | 输入和回显 |
| --- | --- |
| 常用标签 | 首层展示使用频率较高的灰色胶囊，点选后在原位显示标签色，保存的便签沿用该色。点胶囊旁的「＋」，浮层列出全部已有标签，每个名称旁显示对应颜色的圆点，并提供「新建标签」入口。每个日程可选一个标签，点已选标签即可取消。原生首层展示三个常用标签，按已保存日程的使用次数排序。 |
| 重复 | 选项包括不重复、每天、仅工作日、每周、每月。选完在面板回显。「仅工作日」按周一至周五，周末选择时显示首次安排的周一。每月按起始日号，缺少该日的月份跳过。新启用重复只从设置当日或指定的未来日期起排。已有单次日程早于设置日时保留历史原件。编辑器显示所选那一次的日期。点保存后可选择仅这一次、这次及以后或整个系列；更换重复频率时可选择后两个范围。取消范围选择会回到原草稿。删除时同样可选择三个范围。节假日调休和自定义结束日期留待后续。 |
| 提醒 | 默认可不设。可选开始时，或提前 5、10、15、30 分钟、1 小时、1 天。选完回显相对时间，以日程开始为基准。 |
| 备注与附件 | 在「备注」下方的页面留白直接输入，文字随内容向下延伸，不另绘输入框。输入或粘贴网址时文字变蓝。点「完成」或移开焦点后，可直接点网址打开；日程详情中的网址也可直接点开。点「选照片」进入系统相册，点「选文件」进入系统文件选择器，也可从中选音频。取消选择会回到原草稿。附件在备注下列出，可单独移除。返回时保留标题和时段。 |

「新建标签」打开与新建日程同层级的面板，只有名称（支持 emoji）和颜色两项。保留六个常用色，点「自定义颜色」可拖动色相条、选择饱和度与明暗，也可直接输入六位 HEX 色值。完成或取消都直接回到原日程草稿。保存成功后自动选中新建标签，取消保留原选择和日程草稿。

验收样例：新建「项目组会」14:00–15:00，点选「项目」并设提前 10 分钟提醒，在备注附上会议资料。保存后应能从同色便签重新打开，核对资料和 13:50 的提醒。原生版已接入上述入口。系统授权后按可用名额先排最近的提醒，回到应用前台再补排。正式交付还需实机验证重启后附件可访问、改期后通知按新时间触发。

选日试走：写下标题和备注，展开开始日期，连续翻两个月再翻回一个月，选定某个周五。核对上方显示该周、草稿仍在，再用结束时间滚轮延长 15 分钟，检查时长回显。选择「仅工作日」后应保留该设置。手机上的滚轮惯性与月历翻页手感仍需实机试用。

### 其他可选模块

受邀人、行程时间、附件是可选模块的例子。比如「项目组会 14:00–15:00」可以加受邀人、到场前的行程时间和会议资料；「图书馆学习 13:00–16:00」可以只加计时器。三小时表达计划时长，计时器在用户开始和停止后记录实际用时。这些是设计示例，当前仓库的[可选模块清单](../../app/entry/src/main/ets/model/Defaults.ets)列出记录、计数、截止日期、备注和列表。

从卡片排入 Timeline 时，时间便签沿用原卡片及已选模块。每张卡至多安排一个时段，再次拖入即改期。只有日期或估时的卡片，须补齐起止时间才会出现在小时网格。直接从 Timeline 创建的时间块独立存在。

### 其他候选信息

| 候选 | 值得它出现的情境 | 初步取舍 |
| --- | --- | --- |
| 清单归属／分类、#标签、颜色 | 想按主题找到或辨认事项 | 卡片当前用弱关联簇。独立时间块的颜色标签见上文。 |
| 重复规则 | 例如每周组会 | 选「重复」后才补频率与结束条件。 |
| 图片 | 要随事项带上课表或白板照片 | 可在补充资料时添加；录屏里有照片与拍照。 |
| 工作量／难度 | 复盘时想比较事情费不费劲 | 与预计时长、紧急程度分开；待确认复盘用途后筛选。 |
| 整项完成状态 | 需要知道会议或待办是否做完 | 在执行事项时处理，另议与归档、文字项勾选的关系。 |
| AI 灵感、番茄专注 | 需要协助拆解或记录实际投入 | 属于动作和执行记录。可另评估入口，无须在创建时填写。 |

## 建议试走的两条路径

1. 想到「准备组会 PPT」时，点加号，面板从下方上滑，直接输入标题并添加。之后在这张卡上补「预计 45 分钟」，再安排实际时段。每次回来都编辑同一事项。
2. 已知「明天 11:00–12:00 项目组会」时，在 Timeline 点「＋」，输入标题并确认日期、起止时间。如需带上会议资料，在备注写下会议链接或点「选文件」选取文档，再保存时间块。

筛选时先判断两个例子能否顺利表达，再决定可选模块的首批范围，以及每种模块在创建和使用时分别需要哪些操作。
